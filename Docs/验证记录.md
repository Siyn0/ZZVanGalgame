## 手动执行入口

核心验证：

```powershell
& '<Unity Editor 路径>/Unity.exe' -batchmode -nographics `
  -projectPath '<项目路径>' -executeMethod GalgameValidation.Run `
  -logFile '<项目路径>/Logs/GalgameValidation-Final.log'
```

PlayMode 验证：

```powershell
$env:ZZVAN_TEST_SAVE_DIRECTORY = '<项目路径>/Temp/RefactorValidation/PlayModeSaves'
& '<Unity Editor 路径>/Unity.exe' -batchmode -nographics `
  -projectPath '<项目路径>' -runTests -testPlatform PlayMode `
  -testResults '<项目路径>/Logs/GalgamePlayMode.xml' `
  -logFile '<项目路径>/Logs/GalgamePlayMode.log'
```

玩家构建命令：

```powershell
& '<Unity Editor 路径>/Unity.exe' -batchmode -nographics `
  -projectPath '<项目路径>' -executeMethod GalgameBuild.VerifyWindowsBuild `
  -logFile '<项目路径>/Logs/GalgameBuild.log'
```

成功时输出 `Builds/Windows/ZZVan.exe`。应分发整个 Windows 目录，不能只复制 exe。构建目录使用 Builds，避免 Unity 退出时清理 Temp 导致产物消失。
