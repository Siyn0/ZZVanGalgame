# 原界面恢复与后台接入

## 当前入口和原有玩法

打开 `Assets/Scenes/0.unity` 运行。主菜单的开始按钮进入 `0SetName.unity`，在独立命名页确认后进入 `WorkbookStory.unity`，从表格第 2 行开始。主菜单没有新增姓名输入框。

15 个原场景和 5 个原预制体已从 Archive/Prototype 恢复，连同 .meta GUID 保留；场景与预制体本身和归档逐字节相同。所有原场景都已加入 Build Settings，原位置、尺寸、图片引用和动画配置没有重排。

- `playDemo.unity`：原角色移动、跳跃、精灵和碰撞场景。
- `dlc_DotA.unity`：原火枪、肉山、呼吸/射击贴图和血条。
- `NormalDemo`、`choseDemo`、`ChoseDemo_Re`、`achiDemo`：原演示场景。

这些小游戏原本是独立场景，恢复后可直接打开运行；本次没有擅自在主菜单添加新按钮或替它们编造剧情入口。

此前新增的 GameView 脚本界面与 Runtime 单场景入口移到 Archive/ScriptUI，不参与运行。MainStory / DemoStory 及 StoryRunner 保留为独立后台数据与测试示例，不接管原场景界面。

## 存档、对话和音频

GameSession 自动初始化后台，**不创建任何 UI**。原 GameManager 的按钮事件继续有效，Esc 控制原有暂停菜单。

36 个档位仍在 SaveRepository 中。原保存/读取按钮使用 GameManager.selectedSlot（默认 1）；如要做多槽界面，手动制作场景按钮，并绑定 GameManager.SelectSlot(int)、SaveGame()、LoadGame()。本次没有把脚本绘制的槽位面板塞回原界面。

场景档案包含场景路径、变量、最近 50 条日志、音频状态和 ISceneCheckpoint 数据。WorkbookDialoguePresenter 保存工作表行号、最后背景指令行、内容结束状态；TextChange 保存旧场景台词索引；PlayerController 保存原横版角色的位置与速度；HPLoss 保存原 DotA 血量。SceneProgress 在读档时重载场景并恢复状态，避免重复追加当前台词或再次增加好感。

新场景存档仍使用 Application.persistentDataPath/StorySaves，storyId 为 scene。全局收藏独立存放，不随读档回退。老 PlayerPrefs 档案不作导入。

GameAudio 保留独立 BGM / 配音轨，无声台词不会停止上一句配音。恢复后的 BGM/AlwayAudio 组件把原预制体上的音频交给后台播放。名字替换同时支持新文本的 {playerName} 和原场景中的 /PlayerName。

新增日志、成就和鉴赏面板可手动绑定 GameSession.History、Collection、IsUnlocked 等接口；目前没有自动生成这些面板。

## Excel 剧情

源文件：`Assets/Dialogue/DialogueTemplate.xlsx`。当前含 298 条内容、34 个段落，列为：

SequenceName、CharacterName、DialogueText、VoiceFile、PortraitFile、Effect、EffectDuration、HasChoices、Choices、NextRow、BackgroundFile。

选项格式为 `文字|Excel行号;文字|Excel行号`。例如第 11 行的三个选项指向第 12、19、26 行。这里用的是工作表实际行号，不是段落内索引。

执行 `Galgame → Import Dialogue Workbook` 后生成 `Assets/Resources/DialogueWorkbook.asset`。编辑模式下修改 xlsx 会自动重新导入，构建前也会重新导入并验证流程。编辑器直接解析 xlsx，无需安装 Excel；发布版本读取导入好的资源，不在运行中依赖 Excel。导入错误会保留上次成功的数据，控制台显示具体错误。

NextRow 使用实际 Excel 行号，0 表示当前内容终点；有选项的行也填写 0，实际目标由 Choices 决定。分支末尾必须填写共同后续行，不能直接落入下一条平行分支。插入或移动工作表行后应同步更新这些行号。导入器检查目标存在性、不可达内容和循环。

BackgroundFile 空白表示沿用当前背景；`【占位符】` 表示清空背景。现有切 CG 行已填入背景占位符，待素材补齐后改成实际文件名。卧室开场沿用原场景背景。素材按 Assets 中的实际文件名解析。

118 个找不到文件的配音/立绘单元格已按要求改为 `【占位符】`，空白字段保持空白。修改前文件在 `Archive/DialogueInputs`。占位符不会被当作路径读取。WorkbookDialoguePresenter 播放占位或缺失立绘时清空并隐藏立绘 Image，避免残留上一句的人物；下一句有素材时恢复显示。占位配音不启动新音频，上一句已经播放的配音仍按原约定自然结束。原场景文件中的素材引用不变。

已支持解析 San±数值、妹/觉/ZZ 好感、路线变量变化，包括方括号和逗号组合。背景切换由 BackgroundFile 驱动；原始 Effect 字符串仍传给 onEffect，Shake、局部放大和黑幕动画暂未制作，需要在场景中手动绑定。表格中 10 处 X 姓名占位已换成 `{playerName}`。

按本次授权，26 条对白/旁白与 1 条选项文字替换为 `【违规描写】`，行号、人物和数值效果保留。工作表的共享字符串也清除了不再使用的原文。修改前原表保存在 `Archive/DialogueInputs/DialogueTemplate.before-playable.20260930-124830.xlsx`；修改行号记录在 `Logs/WorkbookPreparation.json`。

### 在自己制作的场景中接入

给对话控制对象添加 WorkbookDialoguePresenter，并在 Inspector 中绑定：

1. workbook：DialogueWorkbook.asset；sequence：要播放的段落名。
2. dialogueText、characterName、portrait、background、nameBackground：自己摆好的文本和图片组件。
3. choiceButtons：选项按钮按从上到下填写。四按钮配置的第一个槽位作为额外选项，仅四选项时启用；其余三个维持原布局。
4. 下一句按钮绑定 Next()，并填入 nextButton 字段，便于选项出现时禁用普通推进。
5. onSequenceFinished：连接 NextRow 为 0 且无选项时的事件；需要同场景跳转时调用 GoToExcelRow(int)。completionScene 默认是原主菜单 0。
6. onEffect：绑定自制的舞台效果处理。

该组件不会创建 Canvas、控件或布局；已绑定在 WorkbookStory 中。给其他场景接入时，应移除同一组按钮上的旧推进监听，以及选项上的 SceneChange / AddSan / AddMeiPoint，避免同时推进两套逻辑。
